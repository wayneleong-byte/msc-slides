# 生態網｜熱帶稀樹草原（Phase C 試水 build-r3）

靜態教學互動頁：只做 **savanna** 一系。資料驅動，無 npm 建置。

**build-r3（R3）**：在 R2b 日景稀樹草原配色之上，加四項互動——標題磨砂層、Lab 拖物種入網、左下「網況」動態表、升級待機喚醒層。自研互動與文案；唔抄 DEMO／Lutra 碼或資產。缺相片仍用占位。

## 教學簡化免責

本頁物種與連線為**課堂可見模型**，刻意控層級與數量，**唔等於**真實完整生態系或完整食物網。請以課本與教師說明為準。

## 如何開啟

必須用本機 HTTP 伺服器（`fetch` 讀 JSON，勿直接雙擊開檔）：

```bash
cd /workspace/deliverables/ecoweb-own-2026-11-03/build-r3
python3 -m http.server 8771 --bind 127.0.0.1
```

瀏覽器開啟：`http://127.0.0.1:8771/`

開前請確認 **8771** 空閒。本試水約定 port 為 8771（避開 DEMO clone 慣用 port）。

## R3 四項

1. **標題／簡介磨砂層**：進站先顯示；「開始探索」或點空白處淡出；頂欄「標題／簡介」可再打開。標題層開時唔觸發長待機。
2. **生物球拖動＋Lab 拖入網**：畫布節點可拖，連線即時跟住；實驗室以拖入草地為主（「或點一下加入」為次）；預設**空網**；頂欄「載入示範網」一鍵放齊；詳情「移出實驗室網」／雙擊節點／拖出畫布外可移除。重設＝空網。
3. **網況動態表**：畫布左下自研卡——網內物種、目前篩選下連線、網內總連線、生產者；加入／移除即時更新。
4. **待機喚醒層**：約 60 秒無操作後全畫布淡磨砂＋呼吸／微光＋「輕觸繼續」；標題層／modal 開時唔觸發。
