本頁物種、連線與種群曲線為**課堂可見模型**，刻意控層級與數量，**唔等於**真實完整生態系、完整食物網或真實種群預測。請以課本與教師說明為準。

## 如何開啟

必須用本機 HTTP 伺服器（`fetch` 讀 JSON，勿直接雙擊開檔）：

```bash
cd /workspace/deliverables/ecoweb-own-2026-11-03/build-r4
python3 -m http.server 8771 --bind 127.0.0.1
```

瀏覽器開啟：`http://127.0.0.1:8771/`

開前請確認 **8771** 空閒。本試水約定 port 為 8771（避開 DEMO clone 慣用 port）。**唔部署。**

## R4 種群曲線

- 畫布左下：**多物種時間序列折線**（X＝時間、Y＝種群大小）；標題「種群變化」＋旁註「教學簡化模型」
- 加種／移除／載入示範網／清空／重設後即時重跑模擬並短動畫重播曲線
- 精簡數字列（物種／連線／生產者）保留於曲線卡頂
- 空網：提示「拖入物種後顯示種群曲線」
- 模擬用網內**全關係**邊（不受關係芯片篩選影響）
- 節點圓半徑可隨終末種群微調
