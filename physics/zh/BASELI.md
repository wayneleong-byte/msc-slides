# 基力對照（編號＋全文）

本頁為教學對照列表，**非**官方文件。來源：DSEDJ《本地學制正規教育基本學力要求》及初中／高中自然科學課程指引。物理相關條目列編號＋全文；已有互動章才加連結。高中掛勾標明建議配對／分科。

## 初中（物質科學 · 物理相關）

- **`B-3-6`** 能描述速度和平均速度的含義。 — _暫無互動章_
- **`B-3-7`** 能列舉重力、摩擦力、彈力等生活中常見的力，說明力的作用效果。 — _暫無互動章_
- **`B-3-8`** 知道質量與重力的關係並會進行基本計算。 — _暫無互動章_
- **`B-3-9`** 說明二力平衡的條件。 — _暫無互動章_
- **`B-3-10`** 知道力是物體運動狀態改變的原因，並能運用慣性的概念來解釋常見現象。 — _暫無互動章_
- **`B-3-11`** 初步理解壓強的概念，瞭解改變壓強的方法。 — [已有內容 → 流體](fluids/?level=junior)
- **`B-3-12`** 能描述液體壓強的特點，並能說明阿基米德原理和浮沉的條件。 — [已有內容 → 流體](fluids/?level=junior)
- **`B-3-13`** 知道大氣壓強的測量，瞭解大氣壓的變化及其對生活的影響。 — [已有內容 → 流體](fluids/?level=junior)
- **`B-3-14`** 瞭解聲音的三要素以及聲音產生和傳播的條件，能說出噪音的危害和防治噪音的方法。 — _暫無互動章_
- **`B-3-15`** 能簡要說出光在同種均勻介質中傳播的特點。 — [已有內容 → 光學3D實驗室](../optics-3d/)
- **`B-3-16`** 認識光的反射規律和折射定律，能說明它們在實際中的應用。 — [已有內容 → 光學3D實驗室](../optics-3d/)
- **`B-3-17`** 能畫出簡單的光線反射及折射光路圖。 — [已有內容 → 光學3D實驗室](../optics-3d/)
- **`B-3-18`** 瞭解光的色散和色光的混合。 — [已有內容 → 光學3D實驗室](../optics-3d/)
- **`B-3-19`** 認識電荷及電荷的基本性質，理解電路的基本構成，會連接串聯電路和並聯電路，並畫出電路圖。 — [已有內容 → 電路](circuits/?level=junior)
- **`B-3-20`** 會使用電流表和電壓表。 — [已有內容 → 電路](circuits/?level=junior)
- **`B-3-21`** 理解歐姆定律，並能進行簡單計算。 — [已有內容 → 電路](circuits/?level=junior)
- **`B-3-22`** 能簡要說出電流的熱效應和保險絲的應用。 — [已有內容 → 電路](circuits/?level=junior)
- **`B-3-23`** 瞭解半導體和超導體及其應用對社會產生的影響。 — [已有內容 → 電路](circuits/?level=junior)
- **`B-3-24`** 能說明電功率和電流、電壓之間的關係。 — [已有內容 → 電路](circuits/?level=junior)
- **`B-3-25`** 能區分用電器的額定功率和實際功率。 — [已有內容 → 電路](circuits/?level=junior)
- **`B-3-26`** 能指出磁體的極性，並能畫出常見磁感線以表示磁場。 — [已有內容 → 磁學](magnetism/?level=junior)
- **`B-3-27`** 初步瞭解通電導線周圍存在的磁場，以及通電螺線管周圍磁場的特點。 — [已有內容 → 磁學](magnetism/?level=junior)
- **`B-3-28`** 能簡要說明電磁波的應用及其對人類生活和社會發展的影響。 — [已有內容 → 磁學](magnetism/?level=junior)
- **`B-4-1`** 瞭解能量及其存在的不同形式，知道能量的轉移和轉化，並能列舉電池、電動機、發電機等簡單的能量轉換裝置。 — [已有內容 → 功與能量](energy/?level=junior)
- **`B-4-2`** 能描述功和功率的含義，知道做功的過程就是能量轉化或轉移的過程。 — [已有內容 → 功與能量](energy/?level=junior)
- **`B-4-3`** 瞭解動能和勢能的概念，並能說出影響其大小的因素。 — [已有內容 → 功與能量](energy/?level=junior)
- **`B-4-4`** 簡述能量守恆定律的發現歷史，並會簡單運用能量轉化與守恆的觀點分析物理現象。 — [已有內容 → 功與能量](energy/?level=junior)
- **`B-4-5`** 能說出能源的分類及各類能源的特點，並簡要說明能源與人類生存和社會發展的關係。 — [已有內容 → 功與能量](energy/?level=junior)
