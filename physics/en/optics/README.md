# 澳門科學館｜光學互動教學實驗室（Round 2）


## 專案簡介

本專案提供六個基礎光學互動教學站，以 SVG 與原生
JavaScript 繪製光路，並即時計算相關光學量度。

不使用 WebGL、Canvas API、外部 JavaScript 程式庫、
付費 CDN 或建置工具。

## 專案結構

optics-lab/
├── index.html
├── styles.css
├── app.js
└── README.md

## 開啟方式

方法一：直接開啟

1. 將四個檔案放在同一資料夾。
2. 使用 Chrome、Edge 或 Firefox 開啟 index.html。
3. 點擊上方六站導航即可操作。

方法二：本地 HTTP 伺服器

在專案資料夾執行：

    python -m http.server 8000

然後於瀏覽器開啟：

    http://localhost:8000

不需要 npm install 或任何編譯步驟。

## 六個實驗站

### 01 直線傳播與影子

- 點光源
- 不透明擋板
- 接收屏
- 幾何影區
- 可調整擋板高度與位置
- 影區由直線傳播幾何決定

### 02 反射定律

- 水平平面鏡
- 垂直法線
- 入射光與反射光
- 入射角及反射角弧線
- 入射角滑桿 10° 至 70°
- 強制反射角等於入射角

### 03 平面鏡虛像

- 物點
- 兩條不同的入射光
- 兩條實際反射光
- 鏡後虛線反向延長
- 虛像位於延長線交點
- 像距等於物距

注意：鏡後不繪製實際傳播的實線光路。

### 04 斯涅爾折射

- 上方空氣 n1 = 1.00
- 下方玻璃 n2 = 1.50
- 入射角滑桿
- 法線與角弧
- 自動計算折射角
- 讀數驗證 n1 sin(i) = n2 sin(r)

折射角計算：

    r = asin((n1 / n2) * sin(i))

### 05 稜鏡色散

- 白光入射三角形稜鏡
- 紅、綠、藍三條代表光線
- 稜鏡兩個界面使用斯涅爾定律
- 不同折射率導致不同偏折角
- 紅光偏折較小，藍光偏折較大

模型採用：

    n紅 = 1.490
    n綠 = 1.510
    n藍 = 1.530

這些是教學示例數值，不代表所有玻璃。

### 06 凸透鏡成像

- 主光軸
- 光心 O
- 焦點 F、F′
- 三條標準作圖光線
- 物距滑桿
- 即時計算像距及放大率
- 顯示倒立實像

薄透鏡公式：

    1/f = 1/u + 1/v

    v = fu/(u-f)

    m = -v/u

符號約定：

- 凸透鏡焦距 f > 0
- 實物距 u > 0
- 實像距 v > 0
- 虛像距 v < 0
- 倒立像的放大率 m < 0

本版本的物距範圍均大於焦距，
因此只展示實像情況。

## 操作方法

1. 點擊上方導航切換實驗站。
2. 拖動右側滑桿改變實驗參數。
3. 觀察光路圖與即時量度。
4. 點擊圖中的光線、鏡面、焦點或物件。
5. 右側「物件觀察」顯示相關科學說明。

所有點擊操作均不會觸發零件爆炸或拆解動畫。

## 科學模型限制

1. 所有長度以 SVG 圖示單位表示。
2. 不處理繞射、干涉及偏振。
3. 點光源影子模型不包含半影。
4. 反射模型採理想鏡面。
5. 折射模型採均勻、各向同性透明介質。
6. 色散模型只選取三種代表波長。
7. 凸透鏡模型採理想薄透鏡及近軸近似。
8. 圖中透鏡輪廓只供示意，並非厚透鏡追跡。

## 程式數學自檢

app.js 的 runSelfChecks() 包括：

- 反射角等於入射角
- 30° 斯涅爾折射
- 45° 斯涅爾折射
- 空氣進入玻璃向法線偏折
- 薄透鏡公式
- 平面鏡像距等於物距

若數值檢查失敗，會在瀏覽器開發者工具顯示錯誤。
