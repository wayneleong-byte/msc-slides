# Atlas of Physics｜澳門基力繁中版（MVP）

基於上游 [nathanliow/atlas-of-physics](https://github.com/nathanliow/atlas-of-physics)（**MIT**，Copyright (c) 2026 Nathan Liow）。本目錄為本地 fork：繁中雙入口＋基力分層標籤；非官方教材。

## 本地開啟

```bash
cd /workspace/deliverables/atlas-physics-macau/macau-zh
python3 -m http.server 8765
```

瀏覽器開：http://127.0.0.1:8765/

- 初中入口：`index-junior.html`
- 高中入口：`index-senior.html`
- 基力對照：`BASELI.md`（或瀏覽 `baseli.html`）

章內深鏈可加 `?level=junior` 或 `?level=senior` 過濾頁面（見各頁 `levels` 欄位）。
